# Calories-tracker-1C

Веб-приложение для учета питания, расчета КБЖУ и просмотра динамики потребляемых калорий.

## Возможности

- Добавление блюд с КБЖУ на 100 г.
- Поиск и редактирование блюд.
- Выбор блюда и запись порции на выбранную дату.
- Расчет КБЖУ порций и итогов за день.
- Удаление ошибочных записей дневника.
- График калорий и таблица итогов за выбранный период.

При изменении блюда старые записи дневника сохраняют прежние название
и пищевую ценность.

## Технологии

Python, Streamlit, PostgreSQL, SQLAlchemy, psycopg2, pandas.

## Требования

- Python 3.11 или новее.
- Установленный и запущенный PostgreSQL.
- Git для клонирования репозитория.

Инструкция ниже предназначена для Windows PowerShell.
Приложение разрабатывалось с PostgreSQL 18.

## Установка

Склонируйте репозиторий и перейдите в папку проекта:

```powershell
git clone https://github.com/karpendarya/Calories-tracker-1C.git
cd Calories-tracker-1C
```

Создайте окружение Python и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Подготовка базы данных

В pgAdmin подключитесь к своему серверу PostgreSQL.

Нажмите правой кнопкой на Databases, выберите Create, затем Database
и создайте базу с именем calories_tracker.

Скопируйте пример настроек:

```powershell
Copy-Item .streamlit/secrets.toml.example .streamlit/secrets.toml
```

Откройте .streamlit/secrets.toml и укажите параметры своего сервера:

```toml
[database]
host = "127.0.0.1"
port = 5432
name = "calories_tracker"
user = "postgres"
password = "YOUR_PASSWORD"
```

Замените YOUR_PASSWORD своим паролем PostgreSQL.
При необходимости измените адрес, порт и имя пользователя.

Проверьте подключение и создайте таблицы:

```powershell
.\.venv\Scripts\python.exe -m src.database
.\.venv\Scripts\python.exe init_db.py
```

## Запуск

Выполните из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте адрес, указанный в терминале.

Для остановки приложения нажмите Ctrl + C в терминале.
PostgreSQL должна работать во время использования приложения.

## Использование

1. Добавьте блюда во вкладке «Каталог блюд», указав КБЖУ на 100 г.
2. При необходимости найдите блюдо и измените его данные.
3. Во вкладке «Дневник питания» выберите дату, блюдо и вес порции.
4. Просмотрите записи и итог КБЖУ за день.
5. Во вкладке «Статистика» выберите начало и конец периода.

Дни без записей показаны на графике как 0. Это означает отсутствие
данных в дневнике, а не подтвержденное отсутствие потребления калорий.
